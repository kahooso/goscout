# Task-04: Изменяемый стек

## Задание

**Файл:** `sections/go/pointers/pointers.go`
**Тесты:** `sections/go/pointers/pointers_test.go`

Реализовать стек для `int`:
1. `Push(v int)` — добавить элемент на вершину
2. `Pop() (int, bool)` — снять элемент; bool = false если пуст
3. `Peek() (int, bool)` — посмотреть вершину без снятия; bool = false если пуст
4. `NewStack() *Stack` — конструктор

---

## Моё решение

Все методы с pointer receiver `*Stack` — стек изменяемый, иначе не работает.
Конструктор возвращает `*Stack` с `items: make([]int, 0)`.

В `Pop`: сохранил последний элемент в `last` до обрезки слайса,
затем `s.items = s.items[:len-1]`, вернул `last`.

Nil-проверки добавил в Push и Pop — при nil возвращаем досрочно.

---

## Ошибки и трудности

- В `Pop` сначала обрезал слайс, потом брал последний элемент —
  возвращался не тот элемент. Правильно: `last := s.items[len-1]` ДО обрезки.
- В `Peek` при пустом слайсе делал `s = NewStack()` — локальное переприсвоение,
  не помогало. Правильно: `return 0, false`.
- Nil-check с `s = NewStack()` внутри метода — не работает по той же причине.
- В `TestPop` условие `(v == 0 && ok)` — не проверяет конкретные значения.
  Если Pop вернёт неверное ненулевое число — условие false, баг не поймать.
  Правильно: `v != tc.wantVal || ok != tc.wantOk`.
- В `Errorf` передавал `tc.items` (начальное состояние) вместо `tc.want`.

---

## Что бы сделал иначе

Сразу писать `last := s.items[len-1]` в Pop — сначала запомни, потом обрежь.
Условие в тест-проверке через явные `!= tc.wantVal` — не через захардкоженные значения.

---

## Ключевые пакеты и паттерны

- Pointer receiver `(s *Stack)` — когда метод изменяет структуру
- `&Stack{...}` — создание через адрес struct literal
- `s.items[:len-1]` — обрезка слайса без копирования (уменьшаем len, backing array цел)
- `return val, bool` — идиома "значение + флаг успеха" для операций которые могут не сработать
- Escape analysis: `return &localVar` в Go безопасно — компилятор кладёт в heap
- Рекурсивные структуры требуют `*T` в поле — иначе бесконечный размер
