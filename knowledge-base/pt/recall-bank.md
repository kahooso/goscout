# Банк вопросов — трек PT

Накопительный список вопросов **на воспроизведение** по пройденному материалу курса.
Существует потому, что guided-кейс проверяет узнавание (нужная команда напечатана
абзацем выше), а забывается материал за 2–3 недели. Тесты платформы и собеседование
после интенсива будут спрашивать с нуля.

Ведёт Claude (скилл [`pt-course`](../../.claude/skills/pt-course/skill.md)),
отвечает пользователь письменно, своими словами, **не открывая материал**.

---

## Как это работает

**Разминка — в начале каждой сессии.** 3 вопроса, 5 минут. Приоритет выборки:

1. со статусом ❌ (провалены) — в первую очередь;
2. со статусом ✅, но проверенные больше двух недель назад;
3. 🔲 непроверенные из закрытых тем.

Вопрос из недавно пройденного кейса в разминку **не берётся** — он ещё в оперативной
памяти, проверка ничего не покажет.

**Шафл-тест — на границе главы.** 10–12 вопросов вперемешку по всей закрытой главе,
без группировки по кейсам. Смешение тем принципиально: в реальной задаче никто не
скажет, из какого раздела курса брать ответ.

**Статус меняется по результату.** ❌ → ✅ только после ответа без подсказок.
Ответ «в целом верно, но модель кривая» — остаётся ❌ с уточнением в примечании.

---

## Формат

| Символ | Значение |
|---|---|
| ✅ | сдан своими словами, без материала |
| ❌ | провален или ответ построен на неверной модели |
| 🔲 | ещё не проверялся |

Вопросы формулируются **своими словами** — тексты платформы сюда не копируются
(правило публичности, `00-progress.md`).

## Ключевые термины (English)

- **recall** — воспроизведение по памяти, в отличие от **recognition** (узнавание)
- **spaced repetition** — повторение через нарастающие интервалы
- **interleaving** — перемешивание тем в проверке вместо блочной группировки
- **supply chain attack** — атака через доверенный канал поставки ПО
