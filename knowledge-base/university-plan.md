**Профиль:** `_06` — **Безопасность компьютерных систем (Технологии искусственного
интеллекта в кибербезопасности)**.

> Это якорь стратегии. Универ = **дорога** (что и когда учить). Обучение с Claude = **зал**
> (то же руками на Go, без нейронки-за-меня). goscout = **якорный продукт** с конечной целью
> (сетевой сканер + AI-модуль), к которой ведут версии v0.1→v1→v2. Модель — в `.claude/CLAUDE.md`,
> дорожная карта версий — в `.claude/strategy/learning-strategy.md`.

## Что из этого следует для стратегии

1. **goscout (сетевой scout) ложится на семестр 4 «Компьютерные сети».** Выбор сетей как
   темы якоря — не случайность: это ближайший крупный профильный блок + личный интерес.
2. **Алго-задачи синхронны с «Структурами данных» (сем 2, сейчас).** Не redundant —
   универ даёт теорию (на C), зал закрепляет на Go.
3. **Linux/ОС — ждём универ (сем 3-4).** Сейчас Linux трогается косвенно через goscout
   (бежит на Linux, CI на Linux, сетевые сисколлы). Глубоко — когда универ даст ОС.
4. **AI/ML-безопасность — конечная точка вектора (сем 7-8).** Сейчас НЕ вносим в проект,
   только помечаем как финал. Универ начинает давать ИИ с сем 5 (Основы ИИ).
5. **Криптография — большая универ-линия (сем 5-6-8) + сильная математика.** В goscout-зал
   пока не тянем; появится естественно, когда универ даст основы (возможно TLS в HTTP probe).

## Чего НЕ переносим в зал (оставляем универу)

- Чистая математика (высшая, дискретка, ТВиМС, теоретико-числовые методы) — теория универа.
- Реверс-инжиниринг, электроника, схемотехника — есть в программе, но не вектор
  (reverse/kernel неинтересны). Сдаём, не делаем pet-проект.
- Правовое/организационное обеспечение, этика — теория универа.
