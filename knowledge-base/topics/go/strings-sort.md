# Пакеты strings и sort

## strings

### Функции использованные в task-02

```go
strings.Fields("  hello   world  ") // → ["hello", "world"]
// Разбивает по пробельным символам (\t, \n, пробел). Несколько подряд — ок.

strings.ToLower("Hello GO")  // → "hello go"
strings.ToUpper("Hello GO")  // → "HELLO GO"
// Возвращают новую строку. Оригинал не меняется — строки иммутабельны.

strings.Trim("hello!", ".,!?") // → "hello"
// Убирает с обоих концов любые символы из cutset (не подстроку — каждый символ отдельно).
```

### strings.FieldsSeq (Go 1.23+)

Возвращает итератор `iter.Seq[string]` вместо слайса. Не аллоцирует весь слайс сразу — элементы по одному через `range`. Эффективнее для больших строк. Приставка `Seq` — соглашение для всех функций-итераторов в stdlib.

## sort

### sort.Slice

```go
sort.Slice(slice any, less func(i, j int) bool)
```

Сортирует на месте (in-place). `less(i, j)` должна возвращать `true` если элемент `i` должен стоять раньше `j`.

```go
// по убыванию частоты
sort.Slice(keys, func(i, j int) bool {
    return counts[keys[i]] > counts[keys[j]]
})
```

Функцию можно передать анонимно (как выше) или именованной. Анонимная функция может захватывать переменные из внешнего scope — это замыкание (`counts` доступен без передачи параметром).

### Правило less: только строгое сравнение

| Оператор | Результат |
|----------|-----------|
| `>` | убывание (правильно) |
| `<` | возрастание (правильно) |
| `>=`, `<=` | НЕЛЬЗЯ — нарушает строгое упорядочение |
| `==`, `!=` | НЕЛЬЗЯ — не определяет порядок |

Если `a == b` и `less` использует `>=`, то `less(i,j)` и `less(j,i)` оба `true` — противоречие, алгоритм ломается.
