# Task-02: Счётчик слов

## Задание

**Файл:** `go/tools/collections/main.go`

Написать программу-счётчик слов.

**Что делает программа:**
1. Читает строку текста (hardcode прямо в `main` — не нужно читать из файла)
2. Разбивает на слова через `strings.Fields`
3. Считает вхождения каждого слова через `map[string]int`
4. Сортирует слова по убыванию частоты
5. Выводит топ-10 (или все, если слов меньше 10) в формате:
   ```
   the      : 8
   a        : 5
   go       : 3
   ```

**Пакеты:** `strings`, `sort`, `fmt`

**Требования:**
- Привести слова к нижнему регистру (`strings.ToLower`) перед подсчётом
- Убрать знаки препинания (`strings.Trim` с набором символов `.,!?;:"'()`)
- Не использовать внешних библиотек — только stdlib
- Всё в одном файле `main.go`, функции выделить логически:
  - `countWords(text string) map[string]int`
  - `sortByFreq(counts map[string]int) []string` — возвращает слова отсортированные по частоте
  - `main` — склеивает и выводит

**Дополнительно (обязательно разобрать перед кодом):**
Перед написанием кода — понять модель памяти слайсов. В `sortByFreq` ты будешь работать со слайсами.
Ответь себе на вопрос: чем отличаются `[]string`, `[]*string`, `*[]string`?
Аналогия с C: что из этого похоже на `char *arr[]`, `char **arr`, и `*(char *[])`?

---

## Моё решение

Три функции: `countWords` принимает строку, возвращает `map[string]int`. `sortByFreq` извлекает ключи мэпа в слайс и сортирует через `sort.Slice` с замыканием. `main` склеивает и выводит топ.

Самостоятельно разобрался с `range`, `strings.Fields`, `ToLower`, `Trim`, `counts[v]++`. Спросил про сортировку мэпа — понял почему нужен отдельный слайс ключей.

---

## Ошибки и трудности

- Неверный синтаксис массива в заметках: `[1, 2, 3]` вместо `{1, 2, 3}`
- Неточный вывод что `string` — статический массив (на самом деле read-only slice байт)
- `make(map[string]int, 0)` — лишний `0` (без него то же самое)
- `var keys []string` + `append` без pre-allocate — лучше `make([]string, 0, len(counts))`
- Не знал что `>=` ломает `sort.Slice` — требуется строгое упорядочение

---

## Что бы сделал иначе

Сразу писать `make([]string, 0, len(counts))` вместо `var keys []string` — дешевле по аллокациям.

---

## Ключевые пакеты и паттерны

- `strings.Fields` — разбивка по пробельным символам
- `strings.ToLower` + `strings.Trim` — нормализация слов
- `map[string]int` + `counts[v]++` — идиоматичный счётчик
- `sort.Slice` с замыканием — сортировка слайса по значениям внешнего мэпа
- Pre-allocate слайса: `make([]string, 0, len(m))` перед извлечением ключей
