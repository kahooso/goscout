## Блок A0 — фундамент Go — ✅ закрыт 2026-07-28

**Оба гейта взяты:** устный мок-собес A0.6–A0.9 ([interview-02](../interviews/interview-02.md),
2026-07-25) + blank-slate ретест A0.6 холодным заходом ([retest-01](../interviews/retest-01.md),
2026-07-28, артефакт `sections/go/retest-a06/`). Процедура ретеста — скилл `mock-interview`.

Десять заданий, 2026-04-26 → 2026-07-10 (таблица — в [journal.md](journal.md#журнал-задач-блока-a0)).

### Что освоено

**Освоенные темы:** A0.1 структуры, A0.2 слайсы/мэпы, A0.3 указатели, A0.4 ошибки,
A0.5 горутины, A0.6 каналы+select+context (+ фундамент concurrency: race/mutex/atomic,
deadlock vs goroutine leak; + go tooling), A0.7 интерфейсы (неявная реализация, value/pointer
receiver, itable/vtable, полиморфный раннер, typed-nil), A0.8 stdlib CLI (flag.FlagSet,
os.Open+defer, bufio.Scanner, io.Reader для тестов, stdout/stderr+Fprint, коды выхода 0/1/2,
nil vs empty slice), A0.9 net + worker pool (DialTimeout/JoinHostPort/Listen, пул воркеров
jobs/results, числовая сортировка `slices.Sort` vs лексикографика, `parsePorts` CSV+валидация,
единый образец вывода stdout=данные/stderr=ошибки + `%w`-обёртка вместо имени функции, no-slog для CLI),
**инъекция зависимости через маленький интерфейс + фолбэк** (`Resolver`, `Dialer`; usable zero
value, интерфейс объявляет потребитель), `DialContext` vs `DialTimeout` (два бюджета времени:
per-dial и общий дедлайн, побеждает ранний)

### Как далась тема — заметки по ходу

Уверенность A0.8 (со слов 2026-06-15): «не так уж сложно, основательно затронули теорию».
Тема прошла легче A0.7 — подтверждает «теория ПЕРЕД заданием». ПРОБЕЛ: `os`/потоки —
базовое понимание есть, не автоматизм. Держать для ретеста при закрытии A0.

Уверенность по A0.6 каналам: «понял с подсказками, с нуля не уверен» — держать в уме
для blank-slate ретеста при закрытии A0. A0.7 интерфейсы: «зачем интерфейс» долго не
сходилось, но донеслось через аналогию file_operations — закрыто.


### Продукт как результат блока

Задания A0.6–A0.9 не создавали отдельных программ — каждое **добавляло фичу** в тогдашний
`cmd/goscout/`: параллельный DNS-резолв (A0.6), контракт `Probe` и полиморфный раннер (A0.7),
флаги и чтение wordlist (A0.8), TCP-скан портов через worker pool (A0.9). К закрытию блока
это стало **outpost v0.1** (dns + ports), вынесенным в [собственный репозиторий](https://github.com/kahooso/outpost)
2026-07-28.
