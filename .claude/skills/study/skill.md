# Скилл: study

Единая точка входа в вузовскую сессию. Задача — за 5 минут поднять контекст предмета, освежить старое и договориться, что делаем сегодня. Сам материал не объясняет — передаёт профильному скиллу.

**До действия:** [`TEACHER.md`](../../TEACHER.md), профиль `study`.

## Триггеры

- Назван вузовский предмет: «теорвер», «вышмат», «схемач», «бжд», «ос», «яп», «сети» (+ любые формы) — или файл из `university/`.
- `/study` или `/study <предмет>`.

Словарь названий → папок: `university/README.md`, таблица «Предметы». Неоднозначно — спросить одним вопросом.

## Алгоритм

### 1. Контекст (молча)

0. **Прогресс — первым:** `D:\obsidian-storage\tmrw-tasks\sharaga\<Предмет>.md` (имя файла — таблица «Предметы» в `university/README.md`). Это источник истины по сданному и баллам. Не сходится с трекером — верен Obsidian: поправить трекер и сказать об этом одной строкой.
1. Прочитать `university/<N>-semester/<предмет>/README.md` (трекер) целиком и `private.md`, если есть.
2. Последние 1–2 записи `journal.md`.
3. `recall.md` — вопросы, у которых «Следующий» ≤ сегодня.
4. Ближайшие дедлайны из трекера.

### 2. Одна строка контекста

> Контекст: <предмет> — <где сейчас>, следующее — <шаг>. Ближайшее: <дедлайн / защита, через N дней>.

Если до защиты/экзамена ≤ 2 дней — сказать это первым и предложить режим «защита».

### 3. Разминка (3 вопроса)

По `TEACHER.md` §5: 3 вопроса из `recall.md` со сроком ≤ сегодня, сначала ❌. По одному, ответ — своими словами. После каждого — коротко: верно / где дыра. Статус, ступень, даты — обновить в `recall.md` сразу.

Пропустить разминку, если: банк пуст; пользователь явно сказал «без разминки»; горит дедлайн сегодня. Пропуск — отметить в журнале.

### 4. Что сегодня

Если пользователь уже сказал («хочу разобрать лекцию 3», «сделаем лабу 4») — сразу передать. Иначе — AskUserQuestion, варианты из трекера:

| Режим | Скилл |
|---|---|
| Разобрать тему / лекцию | [`lecture`](../lecture/skill.md) |
| Решать задачи | [`problems`](../problems/skill.md) |
| Делать лабу / отчёт | [`lab`](../lab/skill.md) |
| Готовиться к защите / экзамену | [`defense`](../defense/skill.md) |
| Только повторение | [`recall`](../recall/skill.md) |

Рекомендованный вариант — по трекеру («Следующий шаг») и дедлайнам, первым в списке.

### 5. Новый предмет

Папки нет → создать `university/<N>-semester/<код>/` с `README.md` и `recall.md` из `university/_templates/`, строку в таблицу `university/README.md`. Спросить одним сообщением: что делаем через Claude (лекции / задачи / лабы), форма контроля, где материалы (положить в `C:\Users\ryche\Desktop\gostudy-materials\<N>-semester\<код>\`). Личное (преподаватель, группа) — только в `private.md`.

## Чего не делать

- Не начинать объяснять материал в этом скилле — только контекст, разминка, выбор.
- Не пропускать разминку молча.
- Не читать трекеры других предметов «на всякий случай».
