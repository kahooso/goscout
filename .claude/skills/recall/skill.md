# Скилл: recall

Распределённое повторение через вспоминание (`TEACHER.md` §5). Короткий режим — разминка из `study` (3 вопроса); длинный — отдельная сессия повторения или шафл-тест.

**До действия:** [`TEACHER.md`](../../TEACHER.md), профиль `recall`.

## Триггеры

`/recall`, `/recall <предмет>`, «повторение», «проверь меня», «разминка», «что просрочено», «шафл»; вызов из `study` и `defense`.

## Банки

- Вуз: `university/<N>-semester/<предмет>/recall.md` (шаблон — `university/_templates/recall.md`).
- PT: `knowledge-base/pt/recall-bank.md` (свой формат статусов, интервалы — по `pt-course`).

Без предмета → собрать просроченные из всех вузовских банков и показать сводку: «просрочено: теорвер 4, схемач 7, ОС 2. С чего начнём?».

## Алгоритм

1. **Отбор.** «Следующий» ≤ сегодня; сначала ❌, потом по возрасту. Вопросы, разобранные сегодня/вчера, не брать. Количество: разминка — 3, сессия — 8–10, шафл — 10–15 вперемешку по темам.
2. **Вопрос по одному.** Для важных — сначала уверенность 1–5. Ответ своими словами, без конспекта.
3. **Оценка — честно и коротко.** ✅ — ответил сам, суть и термин верны. ❌ — провал, или «в целом верно, но модель кривая» (примечание: что именно криво). Ошибка при уверенности 4–5 → короткий разбор сразу (это самое ценное).
4. **Интервалы.** ✅ → ступень +1 (1 → 3 → 7 → 14 → 30 дней), «Следующий» = сегодня + интервал. ❌ → ступень 1, «Следующий» = завтра. «Проверен» = сегодня. Обновлять файл после каждого ответа, не в конце.
5. **Итог** (одной таблицей): сколько ✅/❌, какие темы просели. Просела тема целиком (≥ 2 ❌ с одной причиной) → предложить `lecture` по ней, а не новые вопросы.

## Пополнение банка

Новые вопросы добавляют `lecture`, `lab`, `problems`, `defense`. Правила формулировки:
- На воспроизведение и «почему», не «что такое X» (определение узнаётся, а не вспоминается).
- Требовать точное слово/формулу: не «где хранится», а «какой файл и чем отличается от соседнего».
- Один вопрос — одна мысль. ID: `<тема>-<номер>` (`L3-2`, `LR6-4`).
- Свои слова, не копия методички.

## Чего не делать

- Не подсказывать до ответа.
- Не переигрывать ❌ в тот же день.
- Не засчитывать ✅ «по смыслу почти» — это ❌ с примечанием.
