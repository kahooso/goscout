# Как пользоваться этим проектом

Шпаргалка для пользователя: что писать Claude в разных ситуациях.

---

## Стартовое сообщение в новой сессии

Скопируй и отправь **первым** в новой сессии:

```
Подними контекст: прочитай .claude/CLAUDE.md, .claude/strategy/learning-strategy.md
(раздел "Текущая позиция") и memory. Подтверди одной строкой текущий блок,
последний task и следующую задачу. Потом жди мой запрос.
```

Claude должен ответить чем-то вроде:
> Контекст: блок A0, последний task-06 (горутины), следующая — мок-собес перед A0.6 (каналы+context). Готов.

Если ответил **не так** (например, начал генерировать код или предлагать тему вне плана) —
ответь: «Сначала подними контекст», и повтори запрос. Это надёжный сигнал.

## Триггерные фразы по ситуациям

| Хочу | Пишу |
|------|------|
| Получить задание на N часов | «У меня есть N часов, дай задание» |
| Объяснить тему/код/протокол | «Объясни X» |
| Показать код на ревью | «Проверь / ревью» + покажи код |
| Помощь при ошибке/панике | «Не компилируется» / «паника» + текст ошибки |
| Записать тему в vault | «Добавь в vault X» |
| Мок-собес по пройденному | «Мок-собес» / «проверь меня» |
| Закончить сессию (записать всё) | «На этом всё» / «заканчиваем» |
| Тема не из плана, но хочу | «Хочу разобрать X» — Claude уточнит зачем и впишет в стратегию |

## Как задавать вопросы во время кода

Когда пишешь решение задачи и появляется вопрос — **не уходи в чат**.
Оставь комментарий в коде:

```go
// ? Почему здесь pointer receiver, а не value?
func (s *Stack) Push(v int) {
    // ...
}
```

Когда покажешь код на ревью — Claude ответит на все `// ?` прямо в коде,
заменив на `// A: <ответ>`. История твоего мышления сохраняется.

---

## Конец сессии

Когда задача сдана и Claude провёл ревью — напиши **«на этом всё»** или **«заканчиваем»**.
Это запускает скилл `session-debrief` который:
- Спросит что было сложным
- Обновит `tasks/task-NN.md`
- Обновит `topics/go/<тема>.md`
- Обновит roadmap, стратегию, счётчик мок-собеса
- Если создавал новую `cmd/<имя>/` — обновит CLAUDE.md

Без этой фразы Claude может забыть зафиксировать сессию → следующий раз начнётся с потерянным контекстом.

## Если Claude ведёт себя не так

Скажи как именно — он обновит соответствующий `skill.md` или memory.
Например:
- «Ты сразу выдал решение — должен был подсказку. Обнови скилл.»
- «Ты не упомянул видео Тузова на новой теме. Это правило в memory.»
- «Ты пропустил Фазу 1 — это нарушение `give-task`.»

Это улучшает Claude от сессии к сессии. **Не молчи** про корректировки.

---

## Что делать когда сессия теряет фокус

Признаки:
- Claude начал предлагать темы вне `learning-strategy.md`
- Забыл что задача — мок-собес перед A0.6, начал давать A0.6
- Игнорирует `// ?` вопросы в коде
- Слишком быстро даёт готовый код вместо подсказок

Реакция:
- «Стоп. Подними контекст: текущая позиция, последняя задача, что должно быть следующим.»
- Или просто закончи сессию (`на этом всё`) и начни новую со стартовым сообщением выше.
