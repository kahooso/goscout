# goscout

пространство для систематического изучения и практики.
golang и сети, далее os и веб-безопасность.

## структура

```
sections/            задание, код и разбор в одном каталоге
  go/                блок a0 — фундамент языка: structs, collections, logparse,
                     pointers, errors-demo, goroutines, retest-a06 (гейт блока)
  leetcode/          algo-практика, отдельный трек

knowledge-base/
  roadmap/           где я сейчас: 00-roadmap.md (позиция), journal.md (что сделано),
                     archive.md (закрытые блоки)
  strategy/          план будущих блоков и принципы
  topics/            конспекты: go, networks, security, algo
  tasks/             разборы заданий, чей код в другом репозитории (outpost)
  interviews/        мок-собесы и ретесты
  ctf/               picoctf, web + general
  university-plan.md где учебный план вуза совпадает с практикой на go

.claude/             инструкции для claude code: скиллы, шаблоны, очередь работ по репо
```

## как это устроено

каждое задание проходит один цикл: теория до кода → код руками → ревью с разбором ошибок
→ конспект в `topics/`. в task-файле остаётся разбор: что не получилось с первого раза
и почему. код за меня не пишется — claude ведёт вопросами и ревью.

тесты к каждому заданию: обычный случай, граничный, злой. для конкурентности — `-race`.
каждые 8 заданий мок-собес; блок не закрывается, пока его самая сложная тема не написана
с нуля, без подсказок и без конспектов.

## продукт

**[outpost](https://github.com/kahooso/outpost)** — сетевой recon-cli на go: dns, порты,
дальше http и tls. вырос отсюда, вынесен в свой репозиторий 2026-07-28.
