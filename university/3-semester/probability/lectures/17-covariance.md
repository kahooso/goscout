# Ковариация и корреляция: конспект для решения задач

## Рамка

Ковариация отвечает на один вопрос: **две случайные величины меняются вместе или нет?** Например, рост и вес: если рост выше среднего, вес обычно тоже выше среднего. Чтобы это посчитать, нужны три вещи, и идут они в таком порядке:

1. **Случайная величина и её ряд распределения.** С какими вероятностями она принимает какие значения.
2. **Матожидание E и дисперсия D.** Где у величины «центр» и насколько сильно она от него отклоняется.
3. **Ковариация cov и коэффициент корреляции r.** Связаны ли отклонения двух величин между собой.

Всё ниже идёт в этом порядке. Каждый раздел заканчивается формулами, которые нужны для задач. Типы задач с решениями — в разделе 6, задачи для самостоятельного решения — в разделе 7, ответы к ним в самом конце.

**Обозначения преподавателя:** ξ («кси»), η («эта») — случайные величины; на слайдах это ξ₁ и ξ₂. **E** — матожидание, **D** — дисперсия, **cov** — ковариация, **r** — коэффициент корреляции, **p** — вероятность.

## 1. Дискретная случайная величина (ДСВ)

Случайная величина (random variable) — это число, которое получается в результате случайного опыта. Бросили кубик — выпало 1…6. Это ξ.

**Дискретная** (ДСВ, discrete random variable) — значения можно перечислить: 0, 1, 2… Она полностью задаётся **рядом распределения** (probability mass function): таблицей «значение → вероятность».

Пример: ξ — число гербов при двух бросках монеты.

```
ξ  |  0     1     2
p  |  0.25  0.5   0.25
```

**Проверка, которую делают всегда:** сумма вероятностей в ряду = 1. Здесь 0.25 + 0.5 + 0.25 = 1 ✓. Если в задаче одна вероятность неизвестна (p = ?), её находят как раз из этого условия.

> **НСВ** (непрерывная, continuous) принимает любые значения на отрезке, например время ожидания автобуса. Вместо таблицы у неё плотность f(x), а вместо сумм интегралы. Подробнее в п. 8. Для первых задач хватит ДСВ.

## 2. Матожидание E — «среднее значение»

**Зачем:** нужно одно число, которое показывает, где «центр» величины. Если повторить опыт много раз и усреднить результаты, получится как раз E.

**Как считать:** каждое значение умножить на его вероятность и всё сложить. Это среднее, взвешенное вероятностями.

```
Eξ = Σ xᵢ · pᵢ          xᵢ — значения, pᵢ — их вероятности, Σ — сумма по всем i
```

Для примера с монетой:

```
Eξ = 0·0.25 + 1·0.5 + 2·0.25 = 0 + 0.5 + 0.5 = 1
```

В среднем выпадает 1 герб, что сходится со здравым смыслом.

**Матожидание функции от ξ.** Если нужно E(ξ²), сами значения возводим в квадрат, а **вероятности не трогаем**:

```
E(ξ²) = Σ xᵢ² · pᵢ
E(ξ²) = 0²·0.25 + 1²·0.5 + 2²·0.25 = 0 + 0.5 + 1 = 1.5
```

### Свойства E (выписать на поля, нужны постоянно)

```
E(c)      = c                 c — константа (не случайная)
E(c·ξ)    = c · Eξ            константа выносится
E(ξ + η)  = Eξ + Eη           ВСЕГДА, даже если ξ и η зависимы
E(ξ · η)  = Eξ · Eη           ТОЛЬКО если ξ и η независимы
```

## 3. Дисперсия D — «разброс»

**Зачем:** у двух величин может быть одинаковое среднее, но разный разброс. Например, {9, 10, 11} и {0, 10, 20}: среднее у обеих 10, но вторая «скачет» гораздо сильнее. Дисперсия (variance) измеряет, насколько сильно величина отклоняется от своего среднего.

**Определение:** средний квадрат отклонения от среднего.

```
Dξ = E( (ξ − Eξ)² )
```

**Как считают на практике** (это то же самое, только быстрее):

```
Dξ = E(ξ²) − (Eξ)²         «среднее квадратов минус квадрат среднего»
```

Пример с монетой: E(ξ²) = 1.5, Eξ = 1:

```
Dξ = 1.5 − 1² = 0.5
```

**Среднее квадратичное отклонение** (standard deviation): σ = √Dξ. Это тот же разброс, но в исходных единицах. Здесь σ = √0.5 ≈ 0.707.

**Проверка смыслом:** D ≥ 0 всегда. Получилась отрицательная дисперсия — ошибка в арифметике. Чаще всего забыли возвести Eξ в квадрат или возвели в квадрат вероятности.

### Свойства D

```
D(c)       = 0                     у константы разброса нет
D(ξ + c)   = Dξ                    сдвиг разброс не меняет
D(c·ξ)     = c² · Dξ               константа выходит В КВАДРАТЕ
D(−ξ)      = Dξ                    потому что (−1)² = 1
D(ξ + η)   = Dξ + Dη + 2·cov(ξ,η)  общий случай (cov — п. 5)
D(ξ + η)   = Dξ + Dη               если ξ и η независимы
```

⚠️ **Ловушка:** D(ξ − η) = Dξ + Dη − 2cov. Для независимых это **Dξ + Dη**, а не Dξ − Dη. Разброс при вычитании не уменьшается, он складывается.

⚠️ **Опечатка на слайде 3 лекции 17:** в последней строке написано `+ cov(ξ₁, ξ₂)`, а должно быть `+ 2cov(ξ₁, ξ₂)`. Двойка видна строкой выше.

## 4. Совместное распределение двух ДСВ

Когда величин две, задают таблицу **совместного распределения** (joint distribution): в каждой клетке стоит вероятность того, что ξ приняла значение строки, **а одновременно** η приняла значение столбца.

```
         η = −1   η = 0   η = 1
ξ = 0     0.1      0.2     0.1
ξ = 1     0.2      0.1     0.3
```

Клетка (ξ=1, η=1) = 0.3 означает P(ξ = 1 и η = 1) = 0.3.

**Проверка:** сумма **всех** клеток = 1. Здесь 0.1+0.2+0.1+0.2+0.1+0.3 = 1 ✓.

**Как получить ряд распределения одной величины** (маргинальное распределение, marginal distribution):
- для ξ — **сложить строку**: P(ξ = 0) = 0.1 + 0.2 + 0.1 = 0.4; P(ξ = 1) = 0.6;
- для η — **сложить столбец**: P(η = −1) = 0.1 + 0.2 = 0.3; P(η = 0) = 0.3; P(η = 1) = 0.4.

**Независимость** (independence): ξ и η независимы, если **каждая** клетка равна произведению своих маргиналов:

```
P(ξ = x, η = y) = P(ξ = x) · P(η = y)     для ВСЕХ клеток
```

Проверка на примере: клетка (0, −1) = 0.1, а P(ξ=0)·P(η=−1) = 0.4·0.3 = 0.12 ≠ 0.1. Значит, **зависимы**. Чтобы доказать зависимость, хватает одной несовпавшей клетки. Чтобы доказать независимость, проверить надо все.

**E(ξη) по таблице:** для каждой клетки перемножаем три числа — значение ξ, значение η и вероятность в клетке, — потом всё складываем:

```
E(ξη) = Σ по всем клеткам  x · y · p(x, y)
```

Клетки, где x = 0 или y = 0, дают ноль, их можно пропускать. Это экономит время у доски.

## 5. Ковариация cov и коэффициент корреляции r

### Ковариация

**Зачем:** нужно понять, отклоняются ли ξ и η от своих средних **в одну сторону**.

**Определение (слайд 2):** перемножаем отклонения и усредняем.

```
cov(ξ, η) = E( (ξ − Eξ)(η − Eη) )
```

Логика знака:
- обе величины одновременно выше среднего (+·+) или обе ниже (−·−) → произведение положительное → **cov > 0** (растут вместе);
- одна выше, другая ниже (+·−) → **cov < 0** (одна растёт, другая падает);
- закономерности нет → плюсы и минусы взаимно гасятся → **cov ≈ 0**.

**Рабочая формула (вывод на слайде 2), по ней и считают:**

```
cov(ξ, η) = E(ξη) − Eξ · Eη
```

### Свойства cov (слайды 4–5)

```
cov(ξ, ξ)  = Dξ                              ковариация с собой = дисперсия
cov(ξ, η)  = cov(η, ξ)                       симметрия
cov(ξ, c)  = 0                               с константой
cov(a₁ξ + b₁, a₂η + b₂) = a₁·a₂·cov(ξ, η)    множители выходят, сдвиги b пропадают
cov(ξ₁ + ξ₂, η) = cov(ξ₁, η) + cov(ξ₂, η)    раскрываем скобки, как при умножении
ξ, η независимы  ⇒  cov(ξ, η) = 0
```

⚠️ **Обратное неверно.** cov = 0 не означает независимость. Классический пример: ξ принимает −1, 0, 1 с вероятностью 1/3 каждое, η = ξ². Величина η полностью определяется ξ, но cov(ξ, η) = E(ξ³) − Eξ·E(ξ²) = 0 − 0 = 0. Такие величины называют **некоррелированными** (uncorrelated), но они зависимы. Это любимый вопрос на защите.

**Общая формула дисперсии линейной комбинации** (из неё получается почти всё в задачах типа А):

```
D(a·ξ + b·η + c) = a²·Dξ + b²·Dη + 2·a·b·cov(ξ, η)
```

### Коэффициент корреляции

**Зачем:** у ковариации неудобный масштаб. Если перевести рост из метров в сантиметры, cov вырастет в 100 раз, хотя связь осталась той же. Поэтому ковариацию делят на разбросы и получают число без единиц измерения.

```
r(ξ, η) = cov(ξ, η) / √(Dξ · Dη)  =  cov / (σξ · ση)
```

Свойства r:

```
−1 ≤ r ≤ 1                       (слайды 6–7)
|r| = 1   ⇔  η = a·ξ + b          связь строго линейная (все точки на прямой)
r = 1     — прямая растёт (a > 0); r = −1 — прямая убывает (a < 0)
r = 0     — некоррелированы (линейной связи нет, но другая может быть)
r(a₁ξ + b₁, a₂η + b₂) = ± r(ξ, η)   знак «+», если a₁·a₂ > 0, «−», если < 0
```

**Проверка смыслом:** получилось |r| > 1 — где-то ошибка. Обычно забыли корень в знаменателе или неверно посчитали D.

**Обратный ход** (встречается в задачах): если дан r, то `cov = r · √(Dξ · Dη)`.

**Ковариационная матрица** (слайд 8) для двух величин:

```
| Dξ         cov(ξ,η) |
| cov(ξ,η)   Dη       |
```

На диагонали стоят дисперсии (потому что cov(ξ, ξ) = Dξ), вне диагонали — ковариации. Матрица симметричная.

## 6. Типы задач и разобранные примеры

**Как узнать тип по условию:**

| Что дано в условии | Тип | Метод |
|---|---|---|
| Числа Dξ, Dη, cov (или r), просят D(…) / cov(…) / r(…) от выражения | **А — по свойствам** | подставить в формулы свойств, таблицы не нужны |
| Таблица совместного распределения | **Б — по таблице** | алгоритм из 7 шагов ниже |
| Таблица с неизвестным p | **Б′** | сначала p из «сумма = 1», дальше как Б |
| «ξ и η независимы», найти D(…) | **В — независимые** | cov = 0, дисперсии просто складываются с квадратами коэффициентов |
| «Верно ли, что…», «зависимы ли…» | **Г — теория** | п. 4 (проверка клеток) и п. 5 (cov = 0 ≠ независимость) |

### Тип А — разобранный пример

> Dξ = 4, Dη = 9, cov(ξ, η) = −2. Найти: а) D(2ξ − 3η + 5); б) cov(3ξ + 1, −2η + 7); в) r(ξ, η); г) cov(ξ + η, ξ − η).

**а)** Формула линейной комбинации, a = 2, b = −3. Константа +5 на дисперсию не влияет.

```
D(2ξ − 3η + 5) = 2²·Dξ + (−3)²·Dη + 2·2·(−3)·cov
               = 4·4   + 9·9      + (−12)·(−2)
               = 16 + 81 + 24 = 121
```

**б)** Множители выходят, сдвиги пропадают:

```
cov(3ξ + 1, −2η + 7) = 3·(−2)·cov(ξ, η) = −6·(−2) = 12
```

**в)**

```
r = cov / √(Dξ·Dη) = −2 / √(4·9) = −2 / 6 = −1/3 ≈ −0.333
```

Проверка: |r| ≤ 1 ✓. Знак минус — связь обратная, но слабая.

**г)** Раскрываем как произведение скобок: (ξ + η)(ξ − η):

```
cov(ξ+η, ξ−η) = cov(ξ,ξ) − cov(ξ,η) + cov(η,ξ) − cov(η,η)
              = Dξ − cov + cov − Dη
              = Dξ − Dη = 4 − 9 = −5
```

### Тип Б — разобранный пример

> Совместное распределение задано таблицей. Найти cov(ξ, η) и r(ξ, η). Зависимы ли ξ и η?

```
         η = −1   η = 0   η = 1
ξ = 0     0.1      0.2     0.1
ξ = 1     0.2      0.1     0.3
```

**Алгоритм (одинаковый для всех задач этого типа):**

**Шаг 0. Проверка.** Сумма клеток = 1 ✓.

**Шаг 1. Маргиналы** (строки и столбцы):

```
ξ  |  0     1           η  |  −1    0     1
p  |  0.4   0.6         p  |  0.3   0.3   0.4
```

**Шаг 2. Eξ и Eη:**

```
Eξ = 0·0.4 + 1·0.6 = 0.6
Eη = (−1)·0.3 + 0·0.3 + 1·0.4 = 0.1
```

**Шаг 3. E(ξ²), E(η²) и дисперсии:**

```
E(ξ²) = 0²·0.4 + 1²·0.6 = 0.6         Dξ = 0.6 − 0.6² = 0.6 − 0.36 = 0.24
E(η²) = 1·0.3 + 0·0.3 + 1·0.4 = 0.7   Dη = 0.7 − 0.1² = 0.7 − 0.01 = 0.69
```

**Шаг 4. E(ξη)** по клеткам. В строке ξ = 0 все произведения нули, считаем только строку ξ = 1:

```
E(ξη) = 1·(−1)·0.2 + 1·0·0.1 + 1·1·0.3 = −0.2 + 0 + 0.3 = 0.1
```

**Шаг 5. Ковариация:**

```
cov = E(ξη) − Eξ·Eη = 0.1 − 0.6·0.1 = 0.1 − 0.06 = 0.04
```

**Шаг 6. Коэффициент корреляции:**

```
r = 0.04 / √(0.24 · 0.69) = 0.04 / √0.1656 ≈ 0.04 / 0.407 ≈ 0.098
```

**Шаг 7. Вывод и проверка смыслом:** |r| ≤ 1 ✓. Связь положительная, но очень слабая. Зависимость: клетка (0, −1) = 0.1 ≠ 0.4·0.3 = 0.12 → **зависимы**. (Заметь: cov ≠ 0 и без того доказывает зависимость, потому что у независимых cov = 0 всегда.)

### Тип В — разобранный пример

> ξ и η независимы, Dξ = 2, Dη = 3. Найти D(3ξ − 2η + 1).

```
cov = 0 (независимы)
D = 3²·2 + (−2)²·3 + 0 = 18 + 12 = 30
```

## 8. Если на доске НСВ (непрерывные)

Методы те же, меняются только инструменты: сумма превращается в интеграл, вероятность p — в f(x)dx.

```
Eξ    = ∫ x · f(x) dx                       f(x) — плотность, интеграл по всей области, где f ≠ 0
E(ξ²) = ∫ x² · f(x) dx
Dξ    = E(ξ²) − (Eξ)²                       формула та же
E(ξη) = ∫∫ x · y · f(x, y) dx dy            f(x, y) — совместная плотность
cov, r — те же формулы, что для ДСВ
```

Пример: ξ равномерна на [0, 2], то есть f(x) = 1/2 на [0, 2]:

```
Eξ    = ∫₀² x · ½ dx  = ½ · x²/2 |₀² = ½ · 2   = 1
E(ξ²) = ∫₀² x² · ½ dx = ½ · x³/3 |₀² = ½ · 8/3 = 4/3
Dξ    = 4/3 − 1² = 1/3
```

## 9. Как решать у доски

1. Назвать тип: «Дана таблица совместного распределения, значит, считаем маргиналы, потом E, D, cov, r».
2. Слева записать нужные формулы: `cov = E(ξη) − Eξ·Eη`, `r = cov/√(Dξ·Dη)`.
3. Маргиналы записать в виде двух маленьких рядов. Так решение видно всем, и меньше путаницы.
4. Считать по одному числу на строку. Не держать в голове: доска заменяет черновик.
5. В конце сказать вывод: знак r (прямая или обратная связь), сила (|r| близко к 0 или к 1), зависимы или нет.

**Типичные ошибки:**
- D(cξ) = c·Dξ — неверно, должно быть **c²**.
- D(ξ − η) = Dξ − Dη — неверно, будет **Dξ + Dη − 2cov**.
- В E(ξ²) возвели в квадрат вероятности вместо значений.
- Забыли вычесть (Eξ)² при вычислении D.
- Забыли корень в знаменателе r.
- Решили, что из cov = 0 следует независимость.
