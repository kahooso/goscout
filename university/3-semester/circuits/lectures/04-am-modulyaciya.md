# Амплитудная модуляция и схема Amplitude Modulator

Разбор примера `AmplitudeModulator.ms11` из `samples/`. Это материал для описания
принципа работы в отчёте по ЛР-1 и для контрольных вопросов 1–4.

Предыдущее: [[01-osnovy-cepey]], [[02-signaly]]

---

## Зачем вообще нужна модуляция

Задача: передать по радио звук — например, тон 1 кГц. Напрямую не выйдет, по двум причинам.

**1. Антенна.** Эффективная антенна имеет размер порядка четверти длины волны.

```
λ = c / f = 300 000 000 / 1000 = 300 000 м = 300 км
```

Четверть — **75 км антенна**. Нереально. Для 10 кГц уже 7.5 км, для 1 МГц — 75 м.
Чем выше частота, тем компактнее антенна.

**2. Общий эфир.** Все передатчики мира работали бы в одной полосе 20 Гц … 20 кГц
и глушили друг друга. Разделить их нечем.

**Решение:** взять высокочастотное колебание — **несущую** (carrier) — и заставить его
меняться в такт с полезным сигналом. Полезный сигнал называют **модулирующим**
(modulating signal). У каждой станции своя несущая, поэтому они не мешают друг другу.

**Амплитудная модуляция** (amplitude modulation, AM) — способ, при котором полезный
сигнал управляет **амплитудой** несущей. Частота несущей остаётся постоянной.

## Математика АМ

Модулирующий сигнал (низкая частота `Ω`) и несущая (высокая частота `ω`):

```
модулирующий:  s(t) = Um · sin(Ωt)
несущая:       c(t) = Uc · sin(ωt)
```

АМ-сигнал получается **перемножением** несущей на модулирующий сигнал,
**сдвинутый вверх на постоянную составляющую** `A`:

```
u_АМ(t) = (A + Um · sin(Ωt)) · sin(ωt)
           └──── огибающая ────┘   └несущая┘
```

**Огибающая** (envelope) — плавная линия, очерчивающая верхушки быстрых колебаний.
Именно она повторяет форму полезного сигнала. Приёмнику достаточно проследить огибающую,
чтобы вытащить информацию.

### Коэффициент модуляции

**Коэффициент (глубина) модуляции** (modulation index/depth) `m` — насколько сильно
полезный сигнал «раскачивает» амплитуду несущей:

```
m = Um / A
```

Через измеримые с осциллографа величины:

```
m = (Umax − Umin) / (Umax + Umin)
```

где `Umax` и `Umin` — наибольшая и наименьшая амплитуда «бочки» на экране.

| `m` | Что происходит | Оценка |
|---|---|---|
| `m = 0` | амплитуда не меняется, информации нет | нет модуляции |
| `0 < m < 1` | огибающая повторяет сигнал, до нуля не доходит | **норма** |
| `m = 1` (100 %) | огибающая касается нуля | предел, максимальная мощность сигнала |
| `m > 1` | **перемодуляция** (overmodulation): огибающая «переворачивается», форма ломается | брак, приём с искажениями |

**Пример.** На экране `Umax = 8 В`, `Umin = 2 В`.
`m = (8 − 2)/(8 + 2) = 6/10 = 0.6`, то есть 60 %.

### Спектр АМ-сигнала

Раскрыв произведение по формуле произведения синусов, получаем три составляющие:

```
несущая:              ω
нижняя боковая:       ω − Ω
верхняя боковая:      ω + Ω
```

Для примера (`ω` = 10 кГц, `Ω` = 1 кГц): **9 кГц, 10 кГц, 11 кГц**.

Отсюда два важных вывода:

- **Ширина полосы АМ-сигнала = удвоенная частота модулирующего сигнала** (`2Ω` = 2 кГц).
- Информация сидит **только в боковых полосах**. Несущая информации не несёт, но
  съедает больше половины мощности передатчика — главный недостаток АМ.

## Разбор схемы Amplitude Modulator

Схема делает **две вещи подряд** — это полная линия связи в миниатюре:

```
[1] источник → [2] сумматор → [3] перемножитель  ║  [4] перемножитель → [5] ФНЧ + буфер
└──────────── ПЕРЕДАТЧИК (модулятор) ───────────╝  └──── ПРИЁМНИК (демодулятор) ────┘
```

Номера узлов (net) соответствуют подписям на схеме в Multisim.

### Каскад 1. Источник информации — `V9` (узел 1)

`AC_VOLTAGE`, 5 Vpk, **1 кГц**, 0°. В реальном передатчике здесь был бы микрофон.
Это то, что нужно передать.

### Каскад 2. Сумматор `U3` — формирование огибающей (узел 5)

Операционный усилитель `LM741CN` в схеме **инвертирующего сумматора**.
Питание двуполярное: `V12` = +15 В, `V11` = −15 В.

Что на него приходит через резисторы на вход `−`:

| Через | Что | Роль |
|---|---|---|
| `R6` = 10 кОм | `V9`, синус 1 кГц 5 В | полезный сигнал |
| `R7` = 10 кОм (обычный резистор) + переключатель `J2` | земля **или** `V10` = 5 В — выбирает `J2` | **постоянная составляющая `A`**: 0 или 5 В |

Коэффициент по сигнальному входу: `K = −R8/R6 = −10к/10к = −1`.

На выходе (узел 5):

```
u5(t) = −( 5·sin(Ωt) + A )
```

Синусоида перевёрнута (инвертирующая схема) и, если `A ≠ 0`, **сдвинута** на постоянную составляющую.
Это и есть **огибающая** будущего АМ-сигнала.

> **Исправлено 2026-09-16.** Раньше здесь было написано, что `R7` — потенциометр,
> которым плавно регулируется `m`. Это неверно, проверено по скриншоту схемы с номерами узлов.

**`R7` — обычный резистор. `J2` — переключатель на два положения** (`Key = A`).
Он соединяет нижний вывод `R7` (узел 3) либо с землёй, либо с плюсом `V10`.

| Положение `J2` | `A` | Узел 5 (выход `U3`) | Узел 9 (выход `A3`) |
|---|---|---|---|
| **по умолчанию** — `R7` на земле | 0 В | синус ±5 В вокруг нуля | **балансная модуляция** (DSB-SC): «бочки» то сверху, то снизу нуля, огибающая не повторяет сигнал |
| **после нажатия `A`** — `R7` на `+5 В` от `V10` | 5 В | синус от 0 до −10 В | **АМ с `m = 1`** (100 %): огибающая повторяет сигнал и касается нуля |

`m = Um / A = 5 В / 5 В = 1`. Плавно менять `m` в этой схеме нечем — есть только два режима.

**По умолчанию схема работает в режиме балансной модуляции, а не АМ.** Подтверждение —
скриншоты пользователя из ЛР-1: узел 5 (XSC3, 5 V/Div) симметричен, ±4.93 В вокруг нуля;
восстановленный сигнал на узле 16 (XSC1) без постоянного смещения. Классическая «бочка» АМ
появляется только после нажатия `A`. Это наглядно показывает, **зачем нужна постоянная
составляющая**: без неё огибающая не повторяет форму сигнала.

### Каскад 3. Перемножитель `A3` — собственно модуляция (узел 9)

Элемент `MULTIPLIER`, коэффициент 100 мВ/В (`k = 0.1`), смещение 0 В.

| Вход | Что подано |
|---|---|
| `Y` | узел 5 — огибающая |
| `X` | `V13` — **несущая**, 5 Vpk, **10 кГц** |

```
после нажатия A:   u9(t) = 0.1 · u5(t) · u13(t) = −2.5 · (1 + sin(Ωt)) · sin(ωt)
по умолчанию:      u9(t) = −2.5 · sin(Ωt) · sin(ωt)
```

**После нажатия `A` это АМ-сигнал.** Амплитуда быстрых колебаний 10 кГц плавно меняется
от 0 до 5 В с частотой 1 кГц. На экране — классическая «бочка».
По умолчанию — балансная модуляция: «бочки» поочерёдно сверху и снизу нуля.

### Каскад 4. Перемножитель `A4` — синхронный детектор (узел 13)

Начинается приёмник. АМ-сигнал перемножается **ещё раз на ту же несущую** `V14`
(10 кГц, синфазно с `V13` — отсюда название «синхронный»).

Работает тригонометрия:

```
sin(ωt) · sin(ωt) = sin²(ωt) = ( 1 − cos(2ωt) ) / 2
```

То есть после второго перемножения получается:

```
u13(t) = −0.625·(1 + sin(Ωt))  +  0.625·(1 + sin(Ωt))·cos(2ωt)
          └──── полезный НЧ ────┘   └──── мусор на 20 кГц ────┘
```

Полезный сигнал 1 кГц **вернулся на своё место**, а рядом появилась ненужная
составляющая на удвоенной частоте несущей.

### Каскад 5. ФНЧ `R9`+`C2` и буфер `U4` (узлы 14, 16)

**Фильтр нижних частот** (low-pass filter): последовательно `R9` = 15 кОм,
на землю `C2` = 22 нФ. Частота среза:

```
fср = 1 / (2π·R·C) = 1 / (2π · 15000 · 22·10⁻⁹) ≈ 480 Гц
```

| Частота | Что с ней делает фильтр |
|---|---|
| 1 кГц (полезный) | ослабляет примерно в 2.3 раза — проходит |
| 20 кГц (мусор) | ослабляет примерно в 42 раза — давит |

`U4` (`LM741CN` с `R10` в обратной связи) — **буфер/повторитель**, усиление 1.
Он не усиливает, а развязывает: фильтр не «проседает» под нагрузкой.

На узле 16 — **восстановленный сигнал 1 кГц**, амплитуда порядка 0.25–0.3 В.
После нажатия `A` к нему добавляется постоянное смещение около −0.6 В; по умолчанию смещения нет.
Формулы для узла 13 выше записаны для режима АМ (после `A`).

## Ответы на контрольные вопросы 1–4

**1. Что такое амплитудная модуляция?**
Способ передачи информации, при котором полезный низкочастотный сигнал управляет
амплитудой высокочастотного несущего колебания; частота и фаза несущей не меняются.

**2. Коэффициент модуляции.**
`m = Um/A = (Umax − Umin)/(Umax + Umin)`. Показывает глубину изменения амплитуды.
Примеры: `Umax = 8 В`, `Umin = 2 В` → `m = 0.6`. При `m = 1` огибающая касается нуля.
При `m > 1` — перемодуляция, форма огибающей ломается, приём искажается.
В схеме примера после нажатия `A`: `Umax = 5 В`, `Umin = 0` → `m = 1`.

**3. Преимущества и недостатки АМ.**

| Преимущества | Недостатки |
|---|---|
| простейший приёмник (диод + RC-фильтр) | низкая помехоустойчивость: помеха действует на амплитуду напрямую |
| узкая полоса: `2Ω` | КПД: больше половины мощности уходит в несущую, не несущую информации |
| дальнее распространение на низких частотах | обе боковые полосы дублируют информацию — расточительно |
| простой и дешёвый передатчик | качество хуже, чем у ЧМ |

**4. Радиосигнал при передаче цифровой информации.**
Это **амплитудная манипуляция** (ASK, amplitude shift keying). Частный случай —
`OOK` (on-off keying): «1» — несущая есть, «0» — несущей нет. Осциллограмма выглядит
как пачки высокочастотных колебаний, разделённые паузами. Так работает азбука Морзе
и простые радиобрелоки.
