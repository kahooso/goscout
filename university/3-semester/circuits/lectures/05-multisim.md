# Multisim 11: что где лежит

Практическая шпаргалка. Всё проверено руками в ЛР-1 (2026-09-09/10).

---

## Файлы и запуск

- Программа: `D:\National Instruments\Circuit Design Suite 11.0\multisim.exe`
- Примеры: `File → Open Samples` → `C:\Users\Public\Documents\National Instruments\Circuit Design Suite 11.0\samples\`
- Новая схема: `File → New → Schematic Capture`
- Закрыть схему: `File → Close`
- Звёздочка в заголовке `[Имя *]` — есть несохранённые изменения

## Окно

| Область | Где | Что |
|---|---|---|
| Design Toolbox | слева | список открытых схем |
| рабочее поле | центр | схема |
| панель компонентов | второй ряд иконок сверху | кнопки групп деталей |
| панель приборов | вертикальная полоса справа | осциллограф, мультиметр, генератор |
| Spreadsheet View | снизу | результаты и ошибки симуляции |
| строка состояния | самый низ | `Simulating. Tran: 0.022 s` — симуляция идёт |

## Детали

Первая кнопка панели компонентов (иконка ⏚) — `Place Source`. Или меню `Place → Component`.
В окне `Select a Component` выбирается `Group → Family → Component`.

| Нужно | Group | Family | Component |
|---|---|---|---|
| земля | Sources | POWER_SOURCES | `GROUND` |
| генератор синуса | Sources | POWER_SOURCES | `AC_VOLTAGE` |
| постоянное питание | Sources | POWER_SOURCES | `DC_POWER` |
| резистор | Basic | RESISTOR | — |
| конкретная микросхема | кнопка `Search` | — | например `OP297AZ` |

- Повернуть перед установкой — `Ctrl+R`.
- Свойства детали — двойной клик. У `AC_VOLTAGE` на вкладке `Value`:
  `Voltage (Pk)` — **амплитуда, не RMS**; `Frequency (F)`; `Phase`.
- Множители в номиналах: `k`, `m`, `u`, `n`, или единицы из списка справа от поля.
- Если в корпусе несколько усилителей (OP297 — два), Multisim спросит, какой ставить: A или B.

## Провода

- Навести на вывод → появится кружок → тянуть к другому выводу или прямо на провод
  (Multisim поставит точку соединения).
- Удалить: клик по проводу → `Delete`. Отменить действие — `Ctrl+Z`.
- Цвет: правый клик → `Color Segment`. **Цвет провода к осциллографу = цвет луча на экране.**
- Номера узлов: `Options → Sheet Properties → Circuit → Net names → Show all`.
- Брошенный недотянутый провод остаётся на схеме и получает свой номер узла — удалять.

## Симуляция

- Запуск / стоп — `F5`, кнопки ▶ / ■, или `Simulate → Run`.
- Интерактивные ключи: у детали подпись `Key = A` — жми `A` на клавиатуре во время симуляции.

## Осциллограф

- Поставить: панель приборов справа → Oscilloscope. Можно несколько (`XSC1`, `XSC2`, …).
- Открыть панель: двойной клик по прибору.
- `A`, `B` — **входы** (каналы). Выходов нет. `Ext Trig` не нужен.
- У каждого канала `+` и `−`: подключать только `+`, `−` внутри уже на земле.
- Щуп на землю → прямая на нуле (земля относительно земли = 0).
- `Timebase Scale` — время на деление, по горизонтали 10 делений.
  **Правило: на экране 2–3 периода.**

| Сигнал | Timebase |
|---|---|
| 1 кГц | `200 µs/Div` |
| 2 кГц | `100 µs/Div` |
| 10 кГц | `20 µs/Div` |

- `Channel Scale` — вольт на деление.
- `AC / 0 / DC` — связь по входу; `AC` убирает постоянную составляющую.
- `Reverse` — белый фон (для отчёта).

> Ошибка ЛР-1: развёртка 2 ms/Div и 10 ms/Div → 20–100 периодов на экране, всё сплющено
> в сплошную полосу. Прежде чем снимать скриншот — проверить Timebase.

## Настройки среды (пункты методички ЛР-1)

| Что | Где |
|---|---|
| цвета схемы | `Options → Sheet Properties → Circuit → Color` |
| автосохранение | `Options → Global Preferences → Save → Auto-backup` |
| возврат к проводнику компонентов | `Options → Global Preferences → Parts` |

## Скриншоты для отчёта

- `Alt+PrintScreen` — только активное окно, без панели задач и часов.
- `Win+Shift+S` — выделить область.
