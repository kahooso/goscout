## 1. Почему вообще что-то фильтруется

Всё держится на одном факте из ЛР-2: **у конденсатора и катушки сопротивление
зависит от частоты**, а у резистора — нет.

```
Xc = 1 / (2·π·f·C)        Xc — сопротивление конденсатора, Ом
                          f  — частота, Гц
                          C  — ёмкость, Ф

XL = 2·π·f·L              XL — сопротивление катушки, Ом
                          L  — индуктивность, Гн
```

`f` у конденсатора **в знаменателе**, у катушки — **в числителе**. Отсюда:

| | низкая частота | высокая частота |
|---|---|---|
| конденсатор `Xc` | огромное → почти обрыв | маленькое → почти провод |
| катушка `XL` | маленькое → почти провод | огромное → почти обрыв |
| резистор `R` | одинаковое | одинаковое |

Теперь ставим резистор и конденсатор **делителем напряжения** (как в ЛР-2) и
смотрим, что остаётся на второй детали. Входное напряжение делится между двумя
сопротивлениями — но одно из них меняется с частотой, а другое нет. Значит и
делёжка на разных частотах выходит разной. Это и есть фильтр.

## 2. Четыре простейшие схемы

Генератор слева, выход снимаем с **нижней** детали (той, что на землю).

```
ФВЧ на RC                 ФНЧ на RC
вход ─┤├─┬─ выход         вход ─/\/\─┬─ выход
      C  │                     R     │
         R                          ═╪═ C
         │                           │
        ─┴─ земля                   ─┴─ земля
```

- **ФВЧ на RC:** конденсатор последовательно, резистор на землю.
  Низкая частота → `Xc` огромное → почти всё напряжение осело на конденсаторе,
  на выход не дошло. Высокая частота → `Xc` ≈ 0 → конденсатор как провод,
  на выходе почти весь сигнал. **Пропускает высокие.**
- **ФНЧ на RC:** поменять местами. Низкая частота → `Xc` огромное → напряжение
  сидит на конденсаторе, а он и есть выход. Высокая → `Xc` ≈ 0 → конденсатор
  закорачивает выход на землю. **Пропускает низкие.**
- **ФВЧ на RL:** резистор последовательно, катушка на землю (катушка — зеркало
  конденсатора, поэтому схема тоже зеркальная).
- **ФНЧ на RL:** катушка последовательно, резистор на землю.

## 3. АЧХ

**АЧХ** — амплитудно-частотная характеристика. График: по горизонтали частота,
по вертикали — какая доля сигнала прошла.

```
K = Uвых / Uвх            K — коэффициент передачи, безразмерный
                          Uвх  — напряжение на входе фильтра, В
                          Uвых — напряжение на выходе фильтра, В
```

`K = 1` — прошло всё. `K = 0.1` — осталась десятая часть.

Снять АЧХ = поставить частоту, записать оба вольтметра, поделить. Потом следующую
частоту. 10 точек — и по ним кривая.

### Нормировка

```
K̂ = K / Kmax             Kmax — наибольшее K в этом же столбце
```

У лучшей точки получается ровно 1, у остальных меньше. Методичка требует этого
для всех характеристик: только после нормировки графики разных фильтров можно
класть рядом и сравнивать.

### Граничная частота

```
f_гр = 1 / (2·π·R·C)      для RC-фильтра
f_гр = R / (2·π·L)        для RL-фильтра
```

Это частота, на которой `K̂` падает до **0.707** (= `1/√2`). Условная граница:
до неё считаем, что фильтр пропускает, после — что режет. На ней `Xc = R`
(или `XL = R`) — сопротивления сравнялись, напряжение делится пополам… но не
ровно пополам по величине, потому что они складываются не арифметически,
а «по теореме Пифагора»: `Z = √(R² + Xc²)`. Отсюда и берётся 0.707, а не 0.5.

### Как считать Uвых вручную

```
ФВЧ на RC:  Uвых = Uвх · R / √(R² + Xc²)
ФНЧ на RC:  Uвых = Uвх · Xc / √(R² + Xc²)
ФВЧ на RL:  Uвых = Uвх · XL / √(R² + XL²)
ФНЧ на RL:  Uвых = Uвх · R / √(R² + XL²)
```

Сверху — сопротивление той детали, с которой снимаем выход. Снизу — полное
сопротивление цепи `Z`.

## 4. Сложные фильтры: Т- и П-образные

Простой RC-фильтр заваливает АЧХ медленно: после граничной частоты сигнал
слабеет плавно, «хвост» тянется далеко. Если поставить **два звена подряд**,
спад становится круче — фильтр режет резче, граница чётче.

- **Т-образный** (T-section) — по форме буквы «Т»: две детали последовательно
  в линии, одна между ними на землю.
- **П-образный** (Pi-section) — по форме буквы «П»: одна деталь в линии,
  по бокам от неё две на землю.

Платится за это тем, что в полосе пропускания сигнал тоже немного просаживается
(второе звено нагружает первое).

## 5. Резонансные фильтры

Если поставить рядом катушку и конденсатор, на одной частоте происходит
**резонанс**: `XL` и `Xc` становятся равны и гасят друг друга.

```
f0 = 1 / (2·π·√(L·C))     f0 — резонансная частота, Гц
```

Параллельный контур (`L` и `C` параллельно):
- **на резонансе** — сопротивление контура максимальное (в идеале бесконечное);
- **в стороне от резонанса** — маленькое.

Отсюда два разных фильтра из одного и того же контура:

- контур **в линии** (последовательно, сигнал идёт сквозь него) → на резонансе
  контур «обрыв», сигнал не проходит → **режекторный фильтр** (notch), яма на АЧХ;
- контур **на землю** (параллельно выходу) → на резонансе контур «обрыв», не
  мешает, сигнал проходит; в стороне от резонанса контур закорачивает выход →
  **полосовой фильтр** (ПФ, band-pass), горб на АЧХ.

**Полоса пропускания** (bandwidth) — ширина этого горба по уровню 0.707 от
вершины: от нижней граничной частоты до верхней.

## 6. Зачем фильтры нужны

- **Блоки питания.** После выпрямителя напряжение постоянное, но «рваное» — с
  остатками сети 50 Гц. ФНЧ пропускает постоянную составляющую и режет пульсации.
- **Радио.** ПФ выделяет одну станцию из всего, что поймала антенна.
- **Многоканальная связь.** Несколько разговоров пускают по одному проводу на
  разных частотах; на приёме полосовые фильтры разбирают их обратно по каналам.
- **Звук.** Темброблок, кроссовер в колонке (ФНЧ → низкочастотный динамик,
  ФВЧ → высокочастотный).
- **Защита от помех.** ФНЧ на входе схемы режет высокочастотный мусор.

## 7. Последовательное включение фильтров

- **ФНЧ + ФНЧ** — спад после границы становится круче, полоса пропускания
  примерно та же. Применяют, когда нужно резче отделить нужное от ненужного.
- **ФВЧ + ФВЧ** — то же самое, только с другой стороны.
- **ФНЧ + ФВЧ** — ФВЧ отрезает низ, ФНЧ отрезает верх, остаётся полоса
  посередине → получается **полосовой фильтр**. Так делают ПФ без катушек.
