⚠ **Питание ОУ.** На рис. 5 выводы 4 и 7 (питание LM741) никуда не подключены. Если генерации нет / выход 0 —
добавить VCC = +15 В на вывод 7 и VEE = −15 В на вывод 4 (Sources → POWER_SOURCES → VCC / VEE). Проверим на первом скрине.

⚠ **Ключи J1–J3 все на клавише A** — одно нажатие переключает их все. Если режимы не получаются, развести на разные
клавиши (двойной клик → Key) и записать какие.

⚠ **Потенциометр:** «57 %» — доля сопротивления между движком и одним из концов. Какой конец подключён — смотрим по
скрину. От этого зависит, растёт усиление при увеличении % или падает.

## Что должно получиться (расчёт до сборки)

- **Частота генерации:** f₀ = 1 / (2π·R·C) = 1 / (2π · 5 кОм · 15 нФ) ≈ **2,12 кГц** (R = R1 = R2, C = C1 = C2).
- **На f₀ мост Вина ослабляет сигнал в 3 раза** (β = 1/3) и не сдвигает фазу.
- **Условие генерации:** усилитель должен усиливать ≥ 3: K = 1 + R_ос/R3 ≥ 3 → **R_ос ≥ 20 кОм** (половина R4 = 40 кОм).
  При 57 % — R_ос ≈ 22,8 кОм (или 17,2 кОм, если подключён другой конец) → K ≈ 3,28 → генерация есть.
- **Отношение U2/U3 ≈ 3** в режиме генерации (на рис. 5 методички: 0,615/0,205 = 3,0) — это и есть β = 1/3.
- Другая частота: C1 = C2 = 10 нФ → ≈ 3,18 кГц; C1 = C2 = 30 нФ → ≈ 1,06 кГц; R1 = R2 = 10 кОм → ≈ 1,06 кГц.

## Как появились таблицы

`raschet_vse.py` → `zamery.py` → `sborka.py` (как в ЛР-7). Диоды — `IDEALD` из базы Multisim (IS = 1e-14, N = 1),
ОУ в генераторе и режимах 2–3 — идеальный, в интеграторе/дифференциаторе — LM741 (A0 = 2·10⁵, 1 МГц, 0,5 В/мкс, ±14 В).
R_ос = доля · 40 кОм. **Проверка модели:** при 57 % расчёт даёт U2 = 0,616, U3 = 0,205 В — на рис. 5 методички
0,615 и 0,205. Значит, и диоды, и конец потенциометра угаданы.

**Что получилось у модели (знать до сборки):**
- генерация есть при R4 ≥ 52 %, при ≤ 48 % — нет (граница K = 3 ↔ 50 %);
- при 57 %: Uвых ≈ ±0,81 В, f ≈ 2089 Гц (на 1,6 % ниже f0 = 2122 — диоды искажают), Kг ≈ 8 %, нарастание ≈ 3 мс;
- при 100 %: ±0,90 В, f ≈ 1845 Гц, Kг ≈ 24 % — форма заметно хуже;
- C = 10 нФ → ≈ 3133 Гц, C = 30 нФ → ≈ 1044 Гц (амплитуда та же).
