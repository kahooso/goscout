## Факты, которые легко забыть

- **Сеть VMware пропала** (у ВМ нет IP, загрузка висит на `systemd-networkd-wait-online`): Restore Defaults не помогает. Чинить из админского PowerShell через `C:\Program Files\VMware\VMware Workstation\vnetlib.exe -- <cmd>` (set vnet vmnet8 addr/mask, add/update dhcp и nat, update adapter, start dhcp/nat) + службы в Automatic. Код выхода vnetlib = 1 даже при успехе. VMnet8: `192.168.150.0/24`, хост `.1`, шлюз/DNS `.2`, DHCP `.128–.254`, аренды — `C:\ProgramData\VMware\vmnetdhcp.leases`.
- **Грабли сборки на Ubuntu 20.04:** (1) `/usr/bin/pintos`, строка 911 — литеральный байт `0x16` вместо `^V` в `$^V`, Perl 5.30 падает; (2) ядро уходит в цикл перезагрузок (triple fault) на «Pintos booting with» — gcc 9 собирает PIE → `-fno-pie` в `CFLAGS` в `src/Make.config` + `make clean`.
- Антиплагиат: решение должно отличаться от канонического (свои имена, свои комментарии, можно вынести логику в `thread.c`). Главная страховка — понимание кода и защита на словах.
