# Работа №10а — эффективность защитного заземления: ориентир к защите

**Практикум:** `gostudy-materials/3-semester/life-safety/bzhd_uchebn_posobie.pdf`, Работа №10 (стр. 127–146).
**Что за работа:** экспериментально показать принцип защитного заземления —
снижение напряжения прикосновения и тока через человека при замыкании на корпус
в сети с **изолированной нейтралью** (система IT).
**Этап:** повторение перед сдачей (разбор готового отчёта друга, вариант 1).

## Что меряют на стенде
Человек касается корпуса ЭУ. При пробое изоляции на корпусе появляется напряжение,
через тело идёт ток по цепи: фаза → Rкорп → человек (Rh) → обувь (Rоб) → амперметр →
земля → сопротивление/ёмкость изоляции нулевого провода → нулевой провод.
Меряют Uh+об (напряжение на человеке+обуви, ≈ напряжение прикосновения) и Ih (ток
через человека) — без заземления и с заземлителем Rз = 2, 10, 100 Ом.

## Постоянные (вариант 1)
Rh = 1 кОм (тело), Rоб = 1 кОм (обувь), Rкорп = 1 Ом, rиз = 515,1 кОм,
U = 220 В (фаза), f = 50 Гц, ω = 2πf = 2·3,14·50 = 314 рад/с.
Два этапа по ёмкости сети: C = 0,05 мкФ и C = 0,47 мкФ.

## Формула (упрощённая схема, рис.10.12)
|Z| = sqrt( R^2 + rиз·(2R + rиз) / (1 + (ω·C·rиз)^2) )
  R = Rh + Rоб + Rкорп         — без защитного заземления
  R = Rкорп + Rз               — с защитным заземлением
Полный ток:  I = U / |Z|
  Без заземления: Ih = I,         Uh+об = Ih·(Rh+Rоб)
  С заземлением:  Uh+об = I·Rз,    Ih = Uh+об / (Rh+Rоб)

## Результаты друга (расчётные, сверены — сходятся)
C=0,05 мкФ: без зазем. |Z|=63,5к, Ih=3,47 мА, Uh+об=6,94 В;
  Rз=2 → Ih=3,48·10⁻³ мА, Uh+об=0,007 В; Rз=10 → 0,0174 мА; Rз=100 → 0,174 мА.
C=0,47 мкФ: без зазем. |Z|=7,09к, Ih=31 мА (ОПАСНО), Uh+об=62 В;
  Rз=2 → Ih=0,033 мА, Uh+об=0,065 В; Rз=10 → 0,162 мА; Rз=100 → 1,62 мА.
