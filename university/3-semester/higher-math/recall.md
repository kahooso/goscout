# Банк повторения — Высшая математика

Вопросы на **воспроизведение**: отвечаешь своими словами, не открывая конспект. Ведёт Claude (скилл `recall`, правила — `.claude/TEACHER.md` §5).

**Интервалы:** верно → следующий раз через 1 → 3 → 7 → 14 → 30 дней (шаг вперёд по лестнице). Провал → снова через 1 день, статус ❌. «Верно, но модель кривая» — остаётся ❌ с примечанием.

**Разминка:** в начале сессии 3 вопроса, у которых «Следующий» ≤ сегодня; сначала ❌. **Шафл-тест** перед экзаменом/защитой — 10–15 вопросов вперемешку.

| Статус | Значение |
|---|---|
| 🔲 | ещё не проверялся |
| ✅ | ответил сам, без подсказок |
| ❌ | провал или неверная модель |

Ступень — номер текущего интервала: 0 (новый) → 1 д → 3 д → 7 д → 14 д → 30 д.
